# ران‌بوک استقرار سریع: از خرید سرور تا لانچ عملیاتی در ۶۰ دقیقه
**سامانه سرویس‌یار (ServiceYar Enterprise)**

---

### ⏱️ جدول زمان‌بندی ۶۰ دقیقه‌ای استقرار:

```
[00:00 - 00:15] ──► ۱. خرید سرور لینوکس ابری (Ubuntu 22.04 / 2C 4GB RAM)
[00:15 - 00:30] ──► ۲. تنظیم رکوردهای DNS دامنه (A Records برای دامنه اصلی و ساب‌دامین‌ها)
[00:30 - 00:45] ──► ۳. نصب خودکار داکر و کلون مخزن گیت‌هاب (Docker + Docker Compose)
[00:45 - 01:00] ──► ۴. اجرای تک‌دستوری `docker compose up -d` + صدور SSL رایگان Let's Encrypt
```

---

### 🛠️ ۱. مشخصات سرور پیشنهادی (VPS Specs):
- **سیستم‌عامل:** Ubuntu 22.04 LTS (x64)
- **پردازنده و رم:** ۲ هسته (2 vCPU) و ۴ گیگابایت رم (4GB RAM)
- **دیسک:** ۴۰ گیگابایت NVMe / SSD
- **ارائه‌دهندگان معتبر:** ابر آروان (ArvanCloud)، لیارا (Liara)، های‌وب، یا سرور پارس.

---

### 🌐 ۲. تنظیم رکوردهای DNS (در پنل دامنه یا Cloudflare / Arvan DNS):
| نوع رکورد (Type) | نام هاست (Name) | آدرس مقصد (Target/Value) | توضیح |
| :---: | :---: | :---: | :--- |
| **A** | `@` یا `madresehyar.ir` | `SERVER_IP` | پرتال مدیریت مدارس |
| **A** | `api` | `SERVER_IP` | وب‌سرویس بک‌اند |
| **A** | `admin` | `SERVER_IP` | پنل سوپر ادمین |
| **A** | `driver` | `SERVER_IP` | وب‌اپ رانندگان |
| **A** | `parent` | `SERVER_IP` | وب‌اپ والدین |

---

### 🚀 ۳. دستورات تک‌خطی استقرار روی سرور (SSH Run Command):

پس از اتصال به سرور از طریق SSH، اجرای این اسکریپت تمام سرویس‌ها را به صورت خودکار بالا می‌آورد:

```bash
# ۱. به‌روزرسانی و نصب داکر
curl -fsSL https://get.docker.com | sh
apt install -y git

# ۲. کلون مخزن و راه‌اندازی
git clone https://github.com/mytest19861986/sch-srv-anti.git /opt/serviceyar
cd /opt/serviceyar

# ۳. اجرای محیط پروداکشن
docker compose -f docker-compose.prod.yml up -d --build
```

### 🔒 ۴. امنیت و پایش زنده:
- پورت‌های دیتابیس (۵۴۳۲) و ردیس (۶۳۷۹) به صورت داخلی ایزوله بوده و در دسترس عموم اینترنت نیستند.
- فایروال سرور تنها پورت‌های ۸۰ و ۴۴۳ (وب و SSL) و پورت SSH را باز نگه می‌دارد.
- گواهینامه‌های SSL به صورت کاملاً خودکار و تمدیدشونده توسط Caddy / Nginx صادر می‌شوند.
