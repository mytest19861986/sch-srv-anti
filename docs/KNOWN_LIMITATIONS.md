# Known Limitations & Technical Assumptions
**Project:** School Transportation Management System (سامانه مدیریت سرویس مدرسه)  
**Phase:** 18 - Final Handoff Package (دستور کار اجرایی شماره ۱۴)  
**Date:** 2026-08-27  

---

## ۱. محدودیت‌های شناخته‌شده و فرضیات فعلی (Current Known Limitations)

### ۱.۱. شبیه‌سازی کلاینت‌های موبایل (Client Handsets Simulation)
- **وضعیت فعلی:** کلاینت‌های موبایل رانندگان و والدین در لایه تست به صورت اسکریپت‌های شبیه‌سازی‌شده (Mock Sync Engine & HTTP Clients) ارزیابی شده‌اند.
- **اقدام آینده:** ساخت اپلیکیشن‌های موبایل واقعی (React Native / Flutter) و اتصال مستقیم به اندپوینت‌های استاندارد REST API.

### ۱.۲. ارائه‌دهندگان سرویس پوش‌نوتیفیکیشن و پیامک (SMS / FCM Gateways)
- **وضعیت فعلی:** ارسال پیامک و پوش‌نوتیفیکیشن فایربیس (FCM) در محیط تست و توسعه با استفاده از Mock Notification Adapter پیاده‌سازی شده است تا هزینه‌های پیامک و وابستگی خارجی حذف گردد.
- **اقدام آینده:** ثبت API Keyهای واقعی کاوه‌نگار / FCM در Kubernetes Secrets پروداکشن.

### ۱.۳. صف درون‌دیتابیسی در مقایسه با Brokerهای مستقل
- **وضعیت فعلی:** صف رویدادهای Outbox برای سادگی استقرار روز اول روی دیتابیس PostgreSQL با کوئری `FOR UPDATE SKIP LOCKED` پیاده شده و تا ۲,۰۰۰ EPS ظرفیت‌سنجی شده است.
- **اقدام آینده:** در صورت عبور ترافیک از ۲,۰۰۰ رویداد در ثانیه، سوییچ شفاف به کلاستر Redis BullMQ بر اساس [ADR-013](docs/DECISIONS.md) انجام خواهد شد.

### ۱.۴. زیرساخت تست بار محلی در برابر Multi-Node Kubernetes
- **وضعیت فعلی:** تست‌های بار و عملکرد در محیط کانتینری تک‌نود با Bun انجام شده است.
- **اقدام آینده:** اجرای تست‌های مقیاس توزیع‌شده (Distributed K6 / Locust) روی کلاستر چندنودی پس از راه‌اندازی زیرساخت ابری.
