# راهنمای نصب و راه‌اندازی اپلیکیشن «سرویس یار — نسخه رانندگان» (Driver App Install Guide)

## ۱. مشخصات بسته نرم‌افزاری (App Metadata)
- **نام اپلیکیشن**: سرویس یار - راننده
- **شناسه بسته (Package ID)**: `ir.serviceyar.driver`
- **نسخه نرم‌افزار**: `1.0.0-driver-alpha`
- **حجم فایل**: کمتر از ۲۵ مگابایت
- **حداقل نسخه اندروید**: Android 8.0 (API 26) و بالاتر
- **لینک دانلود مستقیم APK**: [دانلود ServiceYar-Driver-v1.0.0.apk](https://github.com/mytest19861986/sch-srv-anti/releases/download/v1.0.0-driver-alpha/ServiceYar-Driver-v1.0.0.apk)

---

## ۲. مراحل نصب روی گوشی اندروید
1. فایل APK را از لینک بالا یا مخزن گیتهاب دانلود کنید.
2. در تنظیمات گوشی، گزینه **"Install from unknown sources" (نصب از منابع ناشناس)** را برای مرورگر یا مدیریت فایل فعال نمایید.
3. روی فایل دانلود شده تپ کرده و گزینه **Install** را بزنید.
4. پس از اتمام، اپلیکیشن با نام و آیکون رسمی **«سرویس یار - راننده»** در لیست برنامه‌ها ظاهر می‌شود.

## ۳. راهنمای تست و ورود آزمایشی (Demo Verification)
- **ایمیل ورود**: `driver@demo.ir`
- **رمز عبور**: `Demo@1234`
- **سناریوی تست آفلاین**:
  - پس از ورود و دریافت مانیفست مسافران، اینترنت گوشی را قطع (حالت هواپیما) کنید.
  - وضعیت سوار/پیاده شدن دانش‌آموزان را ثبت کنید (نشانگر زرد رنگ "در صف ارسال").
  - اینترنت را مجدداً متصل کنید؛ همگام‌سازی دسته‌ای (Batch Sync) خودکار اجرا شده و نشانگر سبز "همگام‌سازی شد" فعال می‌گردد.
