# مستند بایگانی طراحی اولیه (Design Documents Archive Note)

پوشه `temp/` شامل پیش‌نویس‌ها، لاگ‌های جلسات طراحی، بنچمارک‌های اولیه معماری و تصمیم‌گیری‌های زیرساختی پروژه «سرویس یار» می‌باشد.

این اسناد به عنوان تاریخچه مستندات طراحی و تکامل معماری (Architecture Decision Records & Design History) حفظ شده‌اند و تمامی مستندات اجرایی، راهنماها و تعاریف زنده سیستم در پوشه اصلی `docs/` قرار دارند.
