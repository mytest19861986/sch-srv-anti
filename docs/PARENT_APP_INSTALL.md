## ۲. مراحل نصب روی گوشی والدین
1. فایل APK را از لینک بالا دانلود کنید.
2. مجوز نصب برنامه‌های ناشناس را تایید کرده و دکمه **Install** را بزنید.
3. پس از پایان نصب، برنامه با عنوان **«سرویس یار - والدین»** در دسترس خواهد بود.
